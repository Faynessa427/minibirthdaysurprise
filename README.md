# Birthday greeting.
   A simple website built with Javascript, HTML, CSS. Users can personalise the experience by entering a name and favourite color, creating a Unique birthday suprise.
   
# features
   - Customisable colors.
   - Animated heart effect.
   - Responsive design.
   - Birthday greeting.


# Technologies used
  - JAVASCRIPT
  - HTML
  - CSS
